# Ml анализ датасета ObesityDataSet с kaggle
Был взят датасет с различными характеристиками людей(вес, рост и тд.) для классификации по 7 категориям ожирения(недостаток, нормальный вес, ожирение 1 типа и тд.).
### Гипотезы:

1. Признаки weight, height, age, gender будут самые важные по feature importance в дереве
2. Если взять эти 4 важных признака, логистическая регрессия будет работать не хуже(по метрике f1 например).
3. Можно создать новый признак "индекс массы тела", и например еще оставить age. На этих двух признаках модель логистической регрессии должна показать адекватный результат.
4. standartScaler не даст прироста при использовании двух признаков: bmi, age.
5. При использовании двух признаков bmi, age нет смысла в деревьях, достаточно логистической регресии(метрики не будут хуже).

### Выводе по гипотезам:
1. Гипотеза подтвердилась, еще EDA на boxplotах было видно, что остальные числовые характеристики имеют все значения у каждого класса ожирения, поэтому особой информации не несут, что потом подтвердилось по метрикам.
2. Действительно, на logreg метрики составили f1(macro): 0.9082 и 0.9507(улучшилось). Смотреть confusion matrix. Вероятно потому что в реальной жизни ожирение классифицируют всего по росту и весу.
3. С bmi и age logreg показал f1(macro): 0.9507. Смотреть confusion matrix. Далее будет с CV и gridsearch(метрика упадет до 0.9420).
4. При обучении дерева с одинаковыми параметрами, но у одного добавлен был StandartScaler. Результат получился точно таким же по f1. Для деревьев нет смысла в standartScaler. Еще вероятно bmi и age числа близкие к друг-другу по величине(от 0 до 100). У logreg f1 с CV лучший f1 score 0.9347 и 0.942(scaled, unscaled). 
5. Обучили logreg и дерево с gridsearch. CV score получился 0.9420 и 0.9437 соответственно. Вероятно в модели всего 2 признака, поэтому более сложная модель как дерево избыточно.
